🔒 Privacy & safety — where your information goes

Your documents are never uploaded. Procédure is just one page of code that runs inside your own browser (or the desktop app). Even when you use it from the GitHub web address, GitHub only sends you the app. It never receives your files, your questions or your answers. There is no server, no account, no tracking and no analytics.

What stays on this computer
  • Every document you add, the text read from it (including OCR of scanned pages), and the original PDF or image so you can view the real pages
  • Your questions, answers, saved questions, feedback, checklists and notes
  • Settings, glossary, and any API key or GitHub token you enter

These are stored in this browser's private storage for this site (or the desktop app's data folder). Other websites can't read them. Anyone who can use this computer account and browser could open the app and see them, so use your normal computer login and lock screen. Clearing this browser's site data deletes them, so use Export for a backup.

Check it yourself — connections made since this window opened

You can confirm this with your browser's developer tools (F12 → Network). The full source code is public at github.com/kefirman9000/Procedure.

🔐 Lock with a PIN (for shared or work computers)

With a PIN lock, your documents, original files, checklist notes and API keys are encrypted on this computer (AES-256, with a key made from your PIN). Without the PIN they can't be read, and a forgotten PIN can't be recovered. Saved questions, feedback and the glossary aren't encrypted.

Remove everything
Deletes documents, settings, keys, checklists and history from this browser. This can't be undone.
